# Tailer для Android

Устанавливаемое приложение для Android 10 и новее. Русскоязычный интерфейс объединяет чат, управление звонками, Telegram, встроенный 2048 и игровые сценарии.

## Первый запуск

Установите Tailer.apk и откройте Tailer. Чат, заметки, проценты и 2048 доступны сразу. Нужный доступ можно подключить отдельно на экране каждого сценария. На некоторых устройствах Android запрашивает дополнительное подтверждение для приложений, установленных из файла. Если системный переключатель заблокирован, откройте сведения о Tailer в настройках Android и проверьте меню «Разрешить ограниченные настройки». Названия зависят от производителя.

## Звонки

1. Откройте «Звонки» и нажмите «Назначить Tailer». Это меняет системное приложение телефона. Прежнее можно вернуть в настройках приложений по умолчанию.
2. Разрешите уведомления, введите номер с кодом страны, включите автоприём и сохраните правило.
3. При входящем вызове Tailer сравнит номер и через три секунды примет совпавший звонок, если он ещё звонит. Для остальных доступен ручной приём и отклонение. После соединения говорит владелец телефона. Сценарий относится к вызовам, которые обслуживает Android Telecom.

## Telegram

- **Новый диалог.** Введите @username и текст. «Открыть черновик» переносит текст в клиент. «Отправить через Tailer» использует отдельную службу «Tailer · Отправка в Telegram». Она открывает указанный чат и ищет созданный именно для этого запроса черновик. У неё есть 20 секунд, чтобы заменить техническую метку введённым текстом и нажать доступную кнопку отправки. В чате Tailer можно написать «Отправь @username: буду в семь». Результат действия виден в журнале. Статус нажатия кнопки не подтверждает доставку получателю.
- **Входящие сообщения.** Включите доступ «Tailer · Telegram» к уведомлениям. Получите сообщение с действием быстрого ответа, оставьте уведомление на телефоне и нажмите «Обновить список» в Tailer. Выберите чат, задайте текст, включите автоответ и сохраните правило. Tailer передаст текст через действие ответа Telegram при следующем сообщении. Для выбранного чата действует интервал 10 минут.
- **Совместимость.** Предусмотрены пакеты официального Telegram, версии с сайта Telegram и Telegram X. Автоотправка в новый чат зависит от поддержки черновиков по ссылке, доступности поля ввода и подписи кнопки Send / Отправить. При тайм-ауте откройте черновик и проверьте его. Уведомления без быстрого ответа, включая некоторые скрытые предпросмотры, в список чатов не попадут.

## Игры

- **2048.** Выберите «Игры», затем «2048». Играйте свайпом, стрелками или нажмите «Автоигра». Tailer перебирает допустимые ходы и учитывает возможное появление плиток 2 и 4. «Один ход» позволяет наблюдать выбор. Партия и счёт сохраняются на устройстве.
- **Установленная игра.** Откройте «Касания в игре», включите службу «Tailer · Игровые касания» и выберите приложение. Список формируется по игровой категории Android. Нажмите «Отметить точки», коснитесь нужных мест на экране и нажмите «Сохранить». Вернитесь в Tailer, задайте число повторов и паузу. Во время выполнения видна кнопка «Стоп». Сценарий привязан к выбранной игре, ориентации и размеру экрана. Для изменившейся раскладки запишите точки заново. Доступность внедрённых касаний зависит от игры.

## Чат и управление

Примеры команд включают «15% от 2400», «Громкость 30%», «Заметка: купить хлеб», «Сыграй в 2048», «Открой Telegram», «Включи фонарик» и «Открой камеру». Голос вводится через системный распознаватель. На некоторых устройствах ему потребуется сеть. В настройках Tailer можно добавить плитку в шторку Android.

### Нейросети и API-ключи

В настройках выберите OpenAI, Google Gemini или OpenRouter. Укажите идентификатор модели, доступной на вашем API-аккаунте, и нажмите «Подключить API-ключ». Для каждого сервиса Tailer хранит отдельный ключ в зашифрованном виде через Android Keystore. При переключении на ранее подключённый сервис поле ключа можно оставить пустым. Сохранённый ключ OpenAI из версии 1.0 продолжает работать после обновления.

В обычном диалоге выбранная модель получает до десяти последних реплик. Каждый провайдер применяет свои тарифы и квоты.

### Анализ переписки Telegram

1. Выберите «Telegram» → «Анализ переписки». Загрузите сообщения открытого уведомления, вставьте скопированный фрагмент или выберите JSON-экспорт одного чата из Telegram Desktop.
2. Откройте «Посмотреть текст для анализа». В обработку попадают до 40 последних текстовых реплик, до 1600 знаков каждая. Уведомление содержит лишь тот фрагмент, который Telegram передал Android.
3. Введите вопрос или поручение. «Ответить мне» показывает вывод в Tailer. «Составить реплику» готовит текст для собеседника. При нажатии этих кнопок показанный фрагмент и поручение передаются выбранному API-провайдеру.
4. Для отправки исходной формулировки нажмите «Отправить мой вопрос». Ответ модели можно отредактировать и отправить кнопкой «Отправить готовый текст». У уведомления получатель уже указан. Для файла или вставленного текста выберите чат или введите @username. Отправка по имени использует службу Tailer для Telegram.


## Сборка

В архиве находятся исходники приложения и два варианта сборки.

- Откройте папку как Android-проект в Android Studio. Модуль app использует Android Gradle Plugin 8.10.1, compileSdk 36, targetSdk 35 и minSdk 29. Для Gradle-сборки подойдёт Gradle 8.11.1 и JDK 17+.
- В PowerShell из корня проекта выполните `./build.ps1`. Для этого способа нужны JDK, платформа Android SDK 36 или 37 и Android Build Tools 36. Скрипт определяет SDK через ANDROID_SDK_ROOT, ANDROID_HOME или обычную папку установки, а JDK через JAVA_HOME или Android Studio. Можно передать пути параметрами -Sdk и -Jdk. Подписанный APK появится в build-local. Для локальной отладки скрипт создаст свой ключ подписи. Ключ, которым подписан готовый APK, в архив не включён, поэтому самостоятельно собранный APK с новой подписью устанавливается отдельно после удаления прежней сборки.

## Что проверено

На эмуляторе проверены установка, интерфейс, вычисление процентов, автоигра 2048, автоприём выбранного номера и отсутствие автоприёма для другого номера. Для звонков использовался управляемый тестовый провайдер системного Telecom. В отдельном локальном приложении проверены передача RemoteInput, интервал между автоответами, заполнение поля и нажатие отправки для заданного получателя, а также четыре игровых касания по сценарию из двух точек. Проверка с настоящей SIM-картой, авторизованным аккаунтом Telegram и платным ключом OpenAI не выполнялась.
